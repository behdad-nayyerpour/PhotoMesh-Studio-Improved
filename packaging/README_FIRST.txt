PhotoMesh Studio - full offline package / بستهٔ کامل آفلاین
================================================================

ENGLISH - new laptop (Windows 10/11, 64-bit, no internet needed)
 1. Right-click the zip > Properties > tick "Unblock" (if shown) > OK.
 2. Extract it to a SHORT path you can write to, e.g. C:\PhotoMeshStudio
    (not Program Files, not a deep Desktop/Downloads path).
    Result: C:\PhotoMeshStudio\PhotoMeshStudio\install_offline.bat ...
 3. Double-click install_offline.bat (1-3 min). It must print
    "Packages OK" and "COLMAP OK"; it creates the desktop shortcut.
 4. Start "PhotoMesh Studio" from the desktop shortcut.
 5. Optional self-test: run_tests_offline.bat  (expect "... passed").
 6. Updates later (internet only while updating): install Git for Windows (defaults),
    double-click setup_git_update.bat once (browser sign-in to GitHub), then update.bat.
    See UPDATING.md.
 Details, GPU notes, moving projects: INSTALL_OTHER_LAPTOP.md.  What is new: CHANGES.md.

فارسی - لپ‌تاپ جدید (ویندوز ۱۰ یا ۱۱، ۶۴ بیتی، بدون نیاز به اینترنت)
 ۱. روی فایل zip راست‌کلیک کنید > Properties > اگر گزینهٔ «Unblock» هست تیکش را بزنید > OK.
 ۲. فایل را در یک مسیر کوتاه که اجازهٔ نوشتن در آن را دارید باز کنید، مثلاً C:\PhotoMeshStudio
    (نه در Program Files و نه در مسیرهای طولانی Desktop یا Downloads).
    نتیجه: C:\PhotoMeshStudio\PhotoMeshStudio\install_offline.bat ...
 ۳. روی install_offline.bat دوبار کلیک کنید (۱ تا ۳ دقیقه). باید پیام‌های
    «Packages OK» و «COLMAP OK» را ببینید. میان‌بر برنامه روی دسکتاپ ساخته می‌شود.
 ۴. برنامه را با میان‌بر «PhotoMesh Studio» روی دسکتاپ اجرا کنید.
 ۵. اختیاری، آزمون خودکار: run_tests_offline.bat (باید «... passed» نمایش داده شود).
 ۶. به‌روزرسانی‌های بعدی (اینترنت فقط هنگام به‌روزرسانی لازم است): Git for Windows را با تنظیمات پیش‌فرض نصب کنید،
    یک بار روی setup_git_update.bat دوبار کلیک کنید (ورود به GitHub در مرورگر)، و از آن به بعد update.bat. راهنما: UPDATING.md
 جزئیات بیشتر، نکته‌های کارت گرافیک و انتقال پروژه‌ها در INSTALL_OTHER_LAPTOP.md است. فهرست تغییرات در CHANGES.md است.
