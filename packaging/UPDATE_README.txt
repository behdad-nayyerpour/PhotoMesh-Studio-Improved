PhotoMesh Studio code update / به‌روزرسانی کد
=============================================
For a laptop that ALREADY has the portable PhotoMesh Studio installed.
(No install yet? Use PhotoMeshStudio_portable_<date>.zip and README_FIRST.txt instead.)
No new Python packages are needed - no reinstall.

ENGLISH
 1. Close PhotoMesh Studio.
 2. Right-click the zip > Properties > "Unblock" (if shown) > OK.
 3. Extract the zip INTO your installed PhotoMeshStudio folder - the folder that contains
    install_offline.bat and photomesh-studio (e.g. C:\PhotoMeshStudio\PhotoMeshStudio).
    Choose "Replace the files in the destination".
 4. Double-click check_update.bat - it must print "Update OK, version 0.1.4".
 5. Start PhotoMesh Studio from the desktop shortcut.
 The Python environment (.venv), COLMAP/GLOMAP and your projects are kept.
 Problems: Help > Open Log Folder (%LOCALAPPDATA%\PhotoMeshStudio\logs), send the newest photomesh_*.log.

فارسی
 این به‌روزرسانی برای لپ‌تاپی است که نسخهٔ portable برنامه از قبل روی آن نصب شده است.
 (اگر برنامه نصب نیست، از PhotoMeshStudio_portable_<date>.zip و فایل README_FIRST.txt استفاده کنید.)
 به هیچ بستهٔ پایتونی جدیدی نیاز ندارد و نصب دوباره لازم نیست.
 ۱. برنامه را ببندید.
 ۲. روی فایل zip راست‌کلیک کنید > Properties > اگر گزینهٔ «Unblock» هست تیکش را بزنید > OK.
 ۳. فایل zip را «داخل» پوشهٔ نصب‌شدهٔ PhotoMeshStudio باز کنید؛ یعنی پوشه‌ای که
    install_offline.bat و photomesh-studio در آن است (مثلاً C:\PhotoMeshStudio\PhotoMeshStudio).
    وقتی ویندوز پرسید، «Replace the files in the destination» را انتخاب کنید.
 ۴. روی check_update.bat دوبار کلیک کنید؛ باید پیام «Update OK, version 0.1.4» نمایش داده شود.
 ۵. برنامه را مثل همیشه از میان‌بر دسکتاپ اجرا کنید.
 محیط پایتون (.venv)، COLMAP/GLOMAP و پروژه‌های شما دست نمی‌خورند.
 اگر مشکلی پیش آمد: Help > Open Log Folder، و جدیدترین فایل photomesh_*.log را بفرستید.
